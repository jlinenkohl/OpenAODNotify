# Agent Instructions

This repository uses a single canonical instructions file for all AI coding agents:

👉 [`.github/copilot-instructions.md`](.github/copilot-instructions.md)

That file defines project vision, technical constraints, coding conventions, the Git/commit approval policy, and the release protocol. It applies regardless of which agent you are (GitHub Copilot, Gemini, Claude, etc.) — always read it before making changes.

- `GEMINI.md` is kept as a pointer stub for tooling that specifically looks for that filename.
- This `AGENTS.md` is kept as a pointer stub for tooling that follows the generic AGENTS.md convention.
